# Навык: Перенос в TeamPlanner

## Использование

```
/okr-teamplanner <quarter>
```

Этап 4 из четырёх: `/okr-retro → /okr-scope → /okr-stages → /okr-teamplanner`.

## На выходе

```
.okr/<quarter>/plan/teamplanner-<quarter>.csv
```

CSV в UTF-8 с разделителем `;` — открывается в Excel двойным щелчком и
импортируется в Google Sheets.

Скрипт — `<корень установки>/skills/okr-scope/scripts/okr-plan.py` (корень —
куда `install.sh` синкнул навыки, обычно `.claude/`). Ниже он — `okr-plan.py`.

## Колонки по умолчанию

| Колонка | Откуда |
|---|---|
| № | сквозная нумерация строк |
| Программа (OBJ) | `OBJ <id>. <название цели>` |
| KR, Инициатива, PBV, Тег, Команды | инициатива Scope |
| Этап №, Роль, Внешняя команда, Этап | этап из заметок: `1.2.3` — третий этап инициативы 1.2 |
| Условия, Риски, Зависимости, Неопределённости | заметки инициативы, в первой строке инициативы; риски с маркером `[RISK]` |
| Ресурс, Сроки, Комментарий техлида | пустые — заполняют техлиды |

Одна строка — один этап. У `ACTIVITY` без этапов — одна строка на инициативу. Отменённые инициативы (`status: Отменено`) и не взятые в квартал (`in_quarter: false`) в таблицу не попадают.

## Инструкция для LLM

### Этап 0: Вводные

`scope-<quarter>.json` должен быть принят после декомпозиции: `status: принято`,
`phase: stages`. Иначе СТОП: «Сначала /okr-stages <quarter> до „принято“».
Скрипт проверяет это сам и откажется собирать таблицу.

### Этап 1: Выгрузка

```bash
python3 okr-plan.py teamplanner .okr/<quarter>/plan/scope-<quarter>.json .okr/<quarter>/plan/teamplanner-<quarter>.csv
```

### Этап 2: Шаблон команды (если есть)

Если в `okr-config.md` задан `teamplanner_template` — путь к таблице команды
(xlsx или csv):
1. Прочитай строку заголовков шаблона.
2. Сопоставь его колонки с колонками по умолчанию по смыслу. Покажи PO
   таблицу соответствия и спроси подтверждение.
3. Собери `teamplanner-<quarter>.csv` в порядке колонок шаблона. Колонки
   шаблона без соответствия оставь пустыми и назови их в отчёте.

Шаблона нет — оставляй колонки по умолчанию.

### Этап 3: Сводка для PO

По таблице посчитай и покажи:
- строк всего, по ролям (PO / SA / BE / FE / ADR) и по командам;
- этапы внешних команд — отдельным списком, это первые кандидаты на нехватку
  ресурса;
- инициативы с PBV ≥ 7 и неопределённостями — техлидам стоит начать с них.

Таблицу не правь руками: правки — в Scope через `/okr-stages`, потом повторная
выгрузка.

## Отчёт

```
TeamPlanner <quarter>: .okr/<quarter>/plan/teamplanner-<quarter>.csv
Строк N: PO N · SA N · BE N · FE N · ADR N. Внешних этапов N.
Колонки: по умолчанию | по шаблону <путь> (без соответствия: …).

── СТОП ── Передайте таблицу техлидам: они заполняют ресурс и сроки
и отмечают, каким инициативам ресурса не хватает.
```
