# Навык: Validator

## Использование

```
/okr-validate <path>
```

**Параметры:**
- `<path>` — путь к `экватор-<quarter>.md`. `okr-lint.py` проверяет только
  структуру экватор-документа; на других markdown-артефактах пайплайна
  (`OKR-<quarter>.md`, `roadmap.md` и т.д.) он завершится с ошибкой — их
  структура другая.

## Инструкция для LLM

Запусти (путь — относительно корня установки, куда `install.sh` синкнул
навыки; обычно `.claude/skills/...`, зависит от выбора при установке):
```bash
python3 <корень установки>/skills/okr-equator/scripts/okr-lint.py <path>
```
Покажи вывод PO без интерпретации — линтер сам форматирует ошибки. Не
пытайся чинить контент самостоятельно без запроса PO.

## Отчёт

```
<вывод okr-lint.py дословно>

<если exit 0>
── СТОП ── Документ прошёл структурную проверку.
<если exit 1>
── СТОП ── PO: почините отмеченные структурные ошибки, затем повторите /okr-validate.
```
