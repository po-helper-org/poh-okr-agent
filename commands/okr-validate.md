## Использование

```
/okr-validate <path>
```

**Параметры:**
- `<path>` — путь к `экватор-<quarter>.md`. `okr-lint.py` проверяет только
  структуру экватор-документа; на других markdown-артефактах пайплайна
  (`OKR-<quarter>.md`, `roadmap.md` и т.д.) он завершится с ошибкой — их
  структура другая.

## Инструкция для LLM

Следуй процессу из `skills/okr-validate/SKILL.md`.

```

<если exit 1>

```
