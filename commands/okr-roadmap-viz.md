## Использование

```
/okr-roadmap-viz <slug|папка> [что сделать]
```

`<slug>` — имя цели латиницей (`goal-03`), папка `.okr/roadmap/<slug>/`. Первый
запуск собирает roadmap из наработок, следующие правят его; промпт из панели
комментариев страницы — тоже сюда.

## На выходе

```
.okr/roadmap/<slug>/roadmap.md + backlog/*.md   декомпозиция — пишет агент
.okr/roadmap/<slug>/roadmap.json                граф — roadmap.py lint
.okr/roadmap/<slug>/roadmap.html                страница — roadmap.py build
```

## Инструкция для LLM

Следуй процессу из `skills/okr-roadmap-viz/SKILL.md`. Формат —
`skills/okr-roadmap-viz/resources/format.md`. Главное: ты пишешь только md; номера,
недели, граф и страницу считает `roadmap.py`; даты и людей не выдумывай —
неизвестное оформляй подзадачей `ВОПРОС:`; `lint` до «Принято», потом `build`;
правки со страницы переноси в md как есть и отчитывайся по номерам комментариев.

## Отчёт

```
Roadmap «<цель>»: .okr/roadmap/<slug>/roadmap.html
Треков N, этапов N, задач N (со сроками N). Предупреждений: N.

── СТОП ── Откройте страницу. Правки — комментариями и «Скопировать промпт».
```
