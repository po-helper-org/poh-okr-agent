## Использование

```
/okr-justify <quarter> <KR>
```

`<quarter>` — планируемый квартал (`2026Q4`), `<KR>` — инициатива из Scope
(`1.3`). Обычно на этапе `/okr-scope`, когда бизнес решает, брать ли инициативу.

## На выходе

```
.okr/<quarter>/plan/justify-<quarter>-<KR>.json + .html
```

## Инструкция для LLM

Следуй процессу из `skills/okr-justify/SKILL.md`. Формат данных —
`skills/okr-scope/resources/plan_schema.md`, раздел «Обоснование инициативы».
Главное: название, тип, PBV и цель не переписывай — их берёт скрипт из Scope
по `kr`; черновик собери из Scope, у PO спроси только недостающее; цифры не
выдумывай — `[УТОЧНИТЬ]`; рекомендацию ставит только PO. Слайды собирает
`okr-plan.py render`.
