## Использование

```
/okr-deep <quarter> [--background]
```

## На выходе

```
.okr/<quarter>/OKR-<quarter>.md
.okr/<quarter>/okr-<quarter>.html
.okr/<quarter>/artefacts/
```

## Инструкция для LLM

Следуй процессу из `skills/okr-deep/SKILL.md`, стадии — в
`skills/okr-deep/resources/orchestration.md`, срезы аудита — в
`skills/okr-deep/resources/audit.md`.

Главное правило: сначала вопросы к PO, потом документ. Черновик стадии fast
читается только на чтение и не переписывается.

## Отчёт

```
Аудит <quarter>: <N> вопросов к PO, <M> расхождений с контекстом.
Источники: <статус каждого>.

<список вопросов>

── СТОП ── PO: ответьте, и я соберу документ.
```
