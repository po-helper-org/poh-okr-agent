## Использование

```
/okr-present <quarter>
```

`<quarter>` — планируемый квартал (`2026Q4`). Идёт после `/okr-teamplanner`
(и `/okr-jira`, если был).

## На выходе

```
.okr/<quarter>/plan/present-<quarter>.json + .html
```

## Инструкция для LLM

Следуй процессу из `skills/okr-present/SKILL.md`. Формат данных —
`skills/okr-scope/resources/plan_schema.md`, раздел «Презентация». Главное:
факты плана не переписывай в JSON — их считает `okr-plan.py`; спроси
PO только посыл (главная мысль, риски и что с ними делаем, длина спринта, что
нужно от команды). HTML собирает `okr-plan.py render`.
