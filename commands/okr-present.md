## Использование

```
/okr-present <quarter>
```

`<quarter>` — планируемый квартал (`2026Q4`). Идёт после `/okr-teamplanner`
(и `/okr-jira`, если был).

## На выходе

```
.okr/<quarter>/plan/present-<quarter>.json + .data.json + .pptx
```

## Инструкция для LLM

Следуй процессу из `skills/okr-present/SKILL.md`. Формат данных —
`skills/okr-scope/resources/plan_schema.md`, раздел «Презентация». Главное:
факты плана не переписывай в JSON — их считает `okr-plan.py present`; спроси
PO только посыл (главная мысль, вывод из прошлого квартала, риски и что с ними
делаем, ритм, что нужно от команды). Слайды рисует
`skills/okr-present/scripts/build_present_pptx.js`.
