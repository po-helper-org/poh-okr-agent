# Roadmap цели — md как трекер, граф линтером, страница сборщиком

## Ситуация

Roadmap цели жил в html-артефакте: данные — в его базе, правки — мышью на странице.
Агент не мог надёжно его обновлять: каждое изменение означало правку большого html или
базы, номера 3.7.1, недели и стрелки зависимостей приходилось пересчитывать «в голове».
Передать roadmap коллеге без потери данных и вернуть её правки обратно было отдельной
работой.

## Причина

Источником истины был сам рендер. Модель одновременно решала, что сделать (декомпозиция)
и как это нарисовать (вычисления и вёрстка), — второе у LLM нестабильно, а проверить
результат было нечем.

## Решение

Навык `/okr-roadmap-viz` разводит работу на три шага:

- **LLM** пишет только md: паспорт `roadmap.md` (роли, выходные, треки, этапы, целевые
  состояния) и задачи `backlog/*.md` по файлу на задачу, во frontmatter формата Backlog.md.
- **`roadmap.py lint`** проверяет ссылки, циклы (в том числе через зависимости на этап),
  цикл `parent`, порядок дат по зависимостям, считает номера и пишет граф `roadmap.json`
  с `after`/`before` по каждой задаче.
- **`roadmap.py build`** собирает `roadmap.html` по шаблону: данные и начальный слой —
  JSON внутри страницы, шрифты встроены, внешних запросов нет. Одинаковые md — байт
  в байт одинаковая страница; хеш данных — номер сборки.

Вид страницы перенесён из артефакта без изменений. Сверху добавлена панель комментариев:
правый клик по любому элементу карты (или режим «Комментировать») — комментарий агенту
с адресом (номер, файл, неделя). «Скопировать промпт» отдаёт комментарии и правки,
сделанные на странице мышью (сравнение с начальным слоем сборки), одним сообщением.
Правки страницы привязаны к номеру сборки и сбрасываются после пересборки — они уже в md.

## Как проверить

`python3 -m unittest discover -s skills/okr-roadmap-viz/scripts` — 23 теста: эталон
без ошибок, нумерация, граф, ошибки ссылок и циклов, байт-в-байт сборка, экранирование
`</script>`. Руками: `roadmap.py build skills/okr-roadmap-viz/scripts/fixtures/sample`,
открыть страницу, правый клик по задаче → комментарий, сменить статус в карточке,
«Скопировать промпт» — в буфере оба пункта с файлами.

## Уроки

Детерминированное — скрипту, решения — модели. Когда модель пишет только данные, а
вычисляет и рисует код, правка агента становится маленькой и проверяемой, а страница —
воспроизводимой. Канал «комментарий к элементу → промпт» дешевле любого встроенного
редактора и не спорит с md за роль источника истины.
