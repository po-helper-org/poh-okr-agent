# Комментарии для агента по правому клику вместо правки страницы

## Ситуация

Страницы ФАКТ и ПЛАН показывают план, но править их нельзя — данные лежат в JSON, который
собирает агент. Передать пожелание можно было только переписыванием JSON руками или пересказом
в чате: где именно править, терялось.

## Причина

Страница — рендер, а не редактор; встраивать полный редактор в неё значило дублировать форму
JSON, которую всё равно ведёт агент.

## Решение

Правый клик по пункту карточки, строке таблицы или выделенной мышью зоне оставляет комментарий
для агента. Заметки копятся в «корзине» — кнопка «Заметки N» в углу (пока заметок нет, кнопки
нет); по клику — список с кнопками «Скопировать для агента», «Файлом» (сохраняет
`<имя>.comments.json`) и «Очистить». У строк с заметкой — зелёная отметка; Shift плюс правый
клик открывает обычное меню браузера. Агент получает список, правит JSON, пересобирает страницу
и отчитывается по номерам. В PR #11 тот же механизм добавлен на страницу TeamPlanner — заметки
на целях, KR и подзадачах.

## Как проверить

Правый клик по строке — заметка создана, кнопка «Заметки 1» появилась; после «Скопировать
для агента» — буфер со списком; «Файлом» — корректный JSON. Перезагрузка страницы заметки
не теряет.

## Уроки

Рендеримой странице не нужен редактор — ей нужен канал правок с адресацией до элемента.
Правый клик по элементу точнее пересказа в чате и дешевле полноценного редактирования.
