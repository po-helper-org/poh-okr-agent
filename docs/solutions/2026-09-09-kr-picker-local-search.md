# Меню привязки задачи вываливало сорок целей без поиска

## Ситуация

Меню привязки задачи к ключевому результату показывало весь список целей — на живом воркспейсе
больше сорока строк. Найти нужную было тяжело, меню работало как дамп.

## Причина

Список был мал на тестовых данных, и поиск никто не закладывал — масштаб живого воркспейса
всплыл только в работе.

## Решение

По умолчанию не выводится ничего: поле поиска, «Без привязки» и подсказка. Поиск с трёх символов,
максимум пять совпадений. Подбор локальный, без сети и словарей (чистый модуль `src/kr-search.ts`):

- регистр не важен, «ё» сводится к «е»;
- порядок правил от точного к догадке: идентификатор → начало названия → вхождение → начало
  слова → подпоследовательность;
- запрос, набранный в английской раскладке, находит цель с русским названием — не переключённая раскладка учтена;
- при равном совпадении короче название — выше;
- Enter выбирает первое совпадение; «Подтянуть мои OKR» показывается только когда целей нет
  или поиск пуст.

## Как проверить

В панели: «ки» — пусто, «rbyj» — пять целей, введённый номер цели — одна по идентификатору,
«жжжжж» — пусто и предложение импорта. Юнит-тесты поиска проходят.

## Уроки

Любой выбор из списка в интерфейсе начинать с поиска — живой воркспейс всегда больше тестового.
Локальный подбор без словарей дёшев и покрывает раскладку и опечатки.
