# Панель ждала ответа CLI секунды на каждое действие

## Ситуация

Каждое действие панели «Управление целями» — чекбокс, правка, создание — это запуск процесса
`backlog`. Ожидание ответа перед показом результата стоило секунд: список ощущался залипающим,
простая правка требовала ждать.

## Причина

Интерфейс был честным в худшем смысле: сначала CLI, потом экран. Стоимость запуска процесса
платил пользователь на каждом действии.

## Решение

Правки стали оптимистичными: список меняется сразу, CLI отвечает в фоне. Неудачная запись
возвращает список к прежнему виду и показывает причину — состояние не расходится с реальностью
дольше, чем длится команда.

## Как проверить

Отметить задачу выполненной — галочка встаёт мгновенно. Уронить CLI (несовместимая версия,
сломанный воркспейс) — правка откатывается с сообщением об ошибке.

## Уроки

Когда действие — внешний медленный процесс, рисуй результат сразу и откатывай при ошибке:
пользователь не должен ждать подтверждения того, что он уже видит.
