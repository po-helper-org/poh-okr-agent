# Обзорный вид эпиков в TeamPlanner

## Ситуация

Список целей в TeamPlanner раскрывался в детали сразу — оценить квартал сверху не выходило:
чтобы понять, у какого KR нет подзадач или исполнителя, приходилось раскрывать каждый.
Обзора «одна строка на KR» не было, тип инициативы (изменение / поддержка / новое) нигде
не показывался.

## Причина

Страница проектировалась как редактор декомпозиции, обзорный слой не закладывали.

## Решение

KR — строка-обзор: номер, тип строки (включающий эпик или обычный), категория инициативы,
тег, название, взвешенная оценка, число подзадач, ключ трекера, флаги «нет подзадач» /
«без исполнителя», ссылка «Детальнее». Раскрыв KR, видишь тип записи в трекере и подзадачи.
Пункт «Все цели» со сводкой сверху. Поле `category` (изменение / поддержка / новое) проверяется
в `lint`, показывается меткой и переносится через `seed`; в PR #11 добавлены правый клик-заметки
и оценка в днях, убраны кнопки разворачивания всех строк.

## Как проверить

Открыть TeamPlanner — строки KR с флагами видны без раскрытия; фильтр «Все цели» показывает
сводку; категория отображается меткой и проходит `lint`.

## Уроки

Редактору деталей нужен соседний обзорный слой: флаги проблем (нет подзадач, нет исполнителя)
на свёрнутой строке экономят массу раскрытий.
