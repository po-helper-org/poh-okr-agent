# Позиционный разбор вывода CLI молча портил заголовки задач

## Ситуация

Раздел «Управление целями» читает задачи из Backlog.md через его CLI. Разбор человекочитаемого
вывода `--plain` был построчным и позиционным: флаги и метаданные в начале строки, дальше —
название задачи. После обновления Backlog.md до 1.51.0 у строк с подзадачами появился хвост
` (ac: 0/3)` — и разбор молча забирал его в заголовок: в панели задачи отображались с мусорным
суффиксом, ошибки не было.

## Причина

Человекочитаемый вывод не версионирован и не обещает стабильность формата: любое дополнение строки
ломает позиционный разбор без диагностики. Машинный вывод `--json` объявляет `schemaVersion` —
ломающее изменение в нём видно явно.

## Решение

Чтение переведено на `--json`, позиционный разбор `--plain` убран. Заодно плагин стал требовать
Backlog.md 1.51.0 или новее (на этой версии появились дедлайны, на них держится группировка
панели) и на более старой версии отказывается работать с внятным сообщением, а не тихо теряет
функциональность.

## Как проверить

Открыть панель на воркспейсе, где у задач есть подзадачи: заголовки без суффиксов. Запустить
плагин против старой версии CLI — сообщение о несовместимости, а не поломанная панель.

## Уроки

Парсить машинный вывод с версией схемы, а не человекочитаемый текст. Если функциональность
зависит от версии CLI — проверять её при старте и отказываться явно.
