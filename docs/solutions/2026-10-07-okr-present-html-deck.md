# Презентация квартала команде — HTML, а не слайды из редактора

## Ситуация

Финальный шаг планирования — рассказать квартал команде. Презентацию собирали руками
в слайдовом редакторе по данным плана: числа копировались, к следующему пересогласованию
расходились с JSON, и перед каждым показом слайды перелопачивали.

## Причина

Презентация была отдельным артефактом без связи с источником данных; всё вычисляемое в ней —
ручная копия.

## Решение

Команда `/okr-present`: презентация квартала в HTML (`okr-plan.py render`), от общего к частному.
Панель сверху («На весь экран», «PDF»), оглавление слева, навигация с клавиатуры, номер слайда
в адресе; на телефоне — лентой; печать — по слайду на страницу. Структура: титул → вводная
(результаты прошлого квартала, риски, роадмап, инициативы по спринтам) → ретро по каждой цели →
планы (предстоящие работы, роадмап, по каждой цели — инициативы, риски, диаграмма загрузки
по сотрудникам) → что нужно от команды. Факты берутся из принятых TeamPlanner → Scope → ретро;
агент пишет только посыл: сообщения, риски, спринты, просьбы. Промежуточный вариант в формате
редактора слайдов удалён — формат только HTML.

## Как проверить

Собрать демо: слайды без переполнения на широком экране, без горизонтальной прокрутки на узком,
PDF — по странице на слайд. Поменялся JSON — цифры на слайдах новые без правки презентации.

## Уроки

Презентация по данным плана — тоже рендер, а не ручной артефакт: источник один, пересобирается
командой, модель пишет только то, чего нет в данных.
