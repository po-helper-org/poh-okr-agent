# okr-config (шаблон)

Скопируй в корень воркспейса как `okr-config.md` и заполни. Читается
`/okr-index` и всем пайплайном. Всё опционально — незаданное автодетектится
или помечается `UNAVAILABLE` в `MANIFEST.md`.

## team
Название команды/инициативы для шапок отчётов (напр. `GDS`). Пусто →
берётся из `/okr-index`, если определимо, иначе `[УТОЧНИТЬ]`.

## po_name
Имя PO для шапок документов (напр. `Ишманов Алексей`).

## tracker_projects
Коды проектов трекера через запятую (напр. `GDSLV, TLND`). Пусто →
живой статус в `/okr-equator` не подтягивается, всё — ручной ввод PO.

## wiki_space
Ключ пространства Confluence для публикации (опционально). Пусто →
публикация ручная.

## teams
Команды, которые участвуют в планировании, и их состав. Одна команда —
подзаголовок-строка, люди — список «ФИО — роль». Смежные команды помечаются
`(внешняя)`, состав у них можно не писать. `/okr-scope` берёт отсюда
названия, `/okr-teamplanner` — исполнителей этапов. Пусто → команды собираются
из рассказа PO, состав — у PO и техлидов.

```
Витрина Backend
- Иванова Анна — PO
- Смирнова Елена — SA
- Петров Сергей — BE
Биллинг партнёра (внешняя)
```

## role_tags
Роли этапов в `/okr-stages`, через запятую. Дефолт: `PO, SA, BE, FE, ADR`.
Проверка документа не пропустит этап с ролью не из этого списка. В
TeamPlanner роли — полный цикл `PO, ADR, SA, BA, BE, FE, QA, DOPS, RM`
(список задаётся в `roles` документа).

## teamplanner_template
Таблица TeamPlanner команды (xlsx, csv или ссылка на Google Sheets), если она
есть. `/okr-teamplanner` сверит с ней порядок колонок листа и возьмёт состав
команд. Пусто → лист по умолчанию: цель → KR «(общий прогресс)» → этапы
(см. `skills/okr-teamplanner/SKILL.md`).

## pbv_scale
Шкала приоритезации Key Result: `1-9` (Priority Business Value). Новый
пайплайн (`/okr-scope`, `okr-plan.py`) и линтер экватора (`okr-lint.py`)
проверяют только эту шкалу. Другая шкала (напр. `RICE`) работала лишь в
устаревшем `/okr-draft`.

## brand_override
Путь к альтернативному `brandbook.md`, если у команды свои цвета/шрифты
вместо дефолтного (см. `skills/okr-equator/resources/brandbook.md`). Пусто →
дефолтный брендбук.

## leadership_stakeholders
Кому адресован раздел «Что нужно от руководителей» в экваторе (через
запятую, напр. `Д. Зорихин, ГД`). Пусто → раздел собирается без адресата,
PO дополняет вручную.

## quarter_start_month
Месяц начала квартала (`1`, `4`, `7`, `10`). Дефолт: `7` (Q3-стиль
календарного года PO). Используется для авто-подсказки текущего `<quarter>`.
